# تقرير فحص وتطوير شاشة الأصناف والمتغيرات والاقتراحات الذكية

التاريخ: 2026-07-01

## نتيجة الفحص

شاشة الأصناف والمتغيرات كانت مرنة أساساً لأنها تدعم:

- مجموعات / أقسام متداخلة.
- وحدات بيع.
- خصائص ديناميكية.
- قيم خصائص.
- ألوان وصور للقيم.
- تعديل وتعطيل.

لكنها لم تكن كافية لكل التجار لأن التاجر الجديد يحتاج معرفة مسبقة بكيفية تهيئة نشاطه، وكانت القوالب محدودة جداً.

## ما تم تطويره

### 1. قوالب تهيئة حسب النشاط

تمت إضافة قوالب ذكية داخل شاشة:

```txt
/merchant/product-taxonomy
```

تشمل:

- مطعم / كافيه.
- ملابس / أزياء.
- بقالة / سوبرماركت.
- إلكترونيات / جوالات.
- صيدلية / عناية صحية.
- خدمات / حجوزات.

كل قالب يضيف:

- أقسام مناسبة.
- وحدات بيع مناسبة.
- خصائص مناسبة.
- قيم خصائص مناسبة.

مع التأكيد أن هذه القوالب اختيارية ولا تفرض شيئاً على التاجر.

### 2. مناسبة الشاشة لمختلف الأنشطة

بعد التطوير أصبحت الشاشة مناسبة لمعظم الأنشطة:

- متاجر منتجات بسيطة.
- متاجر متغيرات ألوان ومقاسات.
- مطاعم ووجبات.
- بقالات وكميات وعبوات.
- صيدليات وتركيز/حجم/فئة.
- خدمات وحجوزات.
- إلكترونيات بسعات وضمان وألوان.

### 3. اقتراحات ذكية للعميل داخل شاشة منتجات المتجر

تم تطوير واجهة المتجر:

```txt
components/store/storefront-experience.tsx
```

بإضافة قسم:

```txt
أقسام مقترحة لك
```

يعتمد على:

- عدد المنتجات داخل القسم.
- المبيعات.
- المشاهدات.
- التقييم.

ويعرض للعميل أقساماً مقترحة قابلة للنقر والفلترة.

## الملفات المعدلة

components/merchant/product-taxonomy-form.tsx
components/store/storefront-experience.tsx
