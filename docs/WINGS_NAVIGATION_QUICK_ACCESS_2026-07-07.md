# تقرير تحسين الوصول للأجنحة والمتاجر — 2026-07-07

## المطلوب
تحسين تجربة المتسوق في:

1. شريط الأجنحة المتحرك في الرئيسية بإضافة زر أنيق في نهايته يوصل إلى كل الأجنحة.
2. داخل صفحة كل جناح إضافة زر "كل المتاجر" للوصول إلى كل المتاجر التابعة للجناح بدون الاكتفاء بالمعروض المختصر.

## ما تم تنفيذه

### 1) زر في نهاية شريط الأجنحة المتحرك
تم تعديل:

```txt
components/home/home-discovery-zone.tsx
```

أضيف زر أنيق في نهاية عناصر الشريط المتحرك بعنوان:

```txt
كل الأجنحة
```

ويظهر بصيغة CTA واضحة:

```txt
لا تنتظر الشريط → كل الأجنحة
```

ويربط إلى:

```txt
/wings
```

الهدف: لا يضطر المتسوق لانتظار ظهور الجناح داخل الشريط المتحرك.

---

### 2) زر "كل المتاجر" داخل صفحة الجناح
تم تعديل:

```txt
app/wings/[slug]/page.tsx
```

وأضيف زر في قسم متاجر الجناح:

```txt
كل المتاجر
```

ويربط إلى:

```txt
/wings/[slug]/stores
```

---

### 3) صفحة جديدة لكل متاجر الجناح
تم إنشاء:

```txt
app/wings/[slug]/stores/page.tsx
```

تعرض كل المتاجر النشطة التابعة للجناح مع:

- بحث باسم المتجر.
- بحث برقم المتجر.
- بحث بالـ slug.
- Pagination.
- أزرار السابق/التالي.
- زر للعودة للجناح.
- زر لكل الأجنحة.

تم تصميمها بحيث لا نعتمد فقط على أول 48 متجر في صفحة الجناح المختصرة.
