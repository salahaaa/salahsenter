# تقرير تنفيذ: منع تكرار أجنحة الصفحة الرئيسية عند كتالوج فارغ

**التاريخ:** 2026-07-15  
**الحالة:** مكتمل محلياً ومتحقق آلياً.

## ما تم تغييره
- تم تأكيد سبب المشكلة في `components/home/luxury-marketplace-home.tsx`: كان المسار الخالي من المنتجات ينفذ فعلياً `wings.concat(fallbackWings)`، بينما `wings` نفسها تكون `fallbackWings` عند غياب بيانات الأجنحة المنشورة.
- تمت إضافة `lib/home/latest-cards.ts` لبناء بطاقات «أحدث الإضافات» بصورة نقية وقابلة للاختبار.
- عند عدم وجود منتجات، تستخدم الدالة الآن قائمة `wings` مرة واحدة فقط مع إزالة دفاعية للتكرار وفق `id` أو `slug`، ثم حد أقصى ست بطاقات.
- أضيف اختبار `tests/home-latest-cards.test.ts` يغطي:
  - قاعدة بيانات بلا منتجات وبأجنحة افتراضية: لا تكرار ولا مفاتيح React متشابهة.
  - وجود منتج فعلي: المنتج يحافظ على الأولوية ولا يُستبدل ببديل الأجنحة.

## الأثر التشغيلي
- لا يوجد تغيير في قاعدة البيانات أو migrations أو API أو cache أو queue أو التخزين.
- لا تتغير أجنحة أو منتجات حقيقية؛ التغيير يقتصر على مسار العرض البديل للواجهة.
- التعقيد خطي على عدد بطاقات محدود، ولا أثر ملحوظ على الأداء.
