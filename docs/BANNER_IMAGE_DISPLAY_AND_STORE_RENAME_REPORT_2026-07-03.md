# تقرير تعديل اسم المتجر وإصلاح عرض صور البنر — 2026-07-03

## المطلوب
1. تغيير اسم متجر بن باش إلى:
   ```txt
   الصبري للأدوات المنزلية
   ```
2. إصلاح مشكلة صور إعلانات/بنرات الواجهة الرئيسية التي كانت تظهر باهتة جداً.
3. إصلاح عرض لوحة الإعلانات الممولة التي كانت تظهر مقسومة نصف صورة ونصف نص، وجعل الصورة/الإعلان يغطي اللوحة كاملة.

---

## ما تم تنفيذه

### 1) تغيير اسم المتجر في قاعدة البيانات
تم تحديث المتجر في قاعدة البيانات:

```txt
الاسم القديم: بن باش للأدوات المنزلية والنظافة
الاسم الجديد: الصبري للأدوات المنزلية
slug الجديد: al-sabri-home-tools
```

وتم التحقق من قاعدة البيانات، والنتيجة:

```json
{
  "name": "الصبري للأدوات المنزلية",
  "slug": "al-sabri-home-tools"
}
```

كما تم تحديث سكربت الاستيراد:

```txt
scripts/import-ui-inspiration-fixtures.ts
```

حتى لا يعيد الاسم القديم إذا تم تشغيله لاحقاً.

---

### 2) إصلاح صورة بنر الواجهة الرئيسية
تم تعديل:

```txt
components/home/promo-carousel.tsx
```

التغييرات:
- إزالة `opacity-40` التي كانت تجعل الصورة باهتة.
- جعل الصورة تغطي كامل اللوحة:
  ```txt
  object-cover + opacity-100
  ```
- تقليل طبقة التعتيم فوق الصورة.
- جعل النص داخل بطاقة شفافة فوق الصورة بدلاً من أن يطغى عليها.
- زيادة ارتفاع لوحة الإعلان لتبدو كبنر احترافي واضح.

النتيجة: إذا رفع الأدمن صورة من إدارة الإعلانات، تظهر كصورة واضحة وتغطي البنر بالكامل، وليس كخلفية باهتة.

---

### 3) إصلاح لوحة الإعلانات الممولة
تم تعديل:

```txt
components/home/luxury-marketplace-home.tsx
```

في قسم:

```txt
MarketplaceAdsSection
```

التغييرات:
- إلغاء تقسيم الإعلان إلى نصف صورة ونصف نص.
- جعل صورة الإعلان تغطي كامل اللوحة.
- وضع النص فوق الصورة داخل طبقة زجاجية شفافة.
- الحفاظ على زر "اكتشف العرض" فوق الصورة.

النتيجة: الإعلان الممول أصبح يظهر كبنر كامل احترافي، وليس بطاقة مقسومة.
