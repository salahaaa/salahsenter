# تقرير تحسين عرض الأصناف داخل واجهة المتجر — 2026-07-04

## المشكلة
في صفحة متجر مثل:

```txt
/store/elite-fashion-import
```

كانت صور الأصناف/المجموعات تظهر مقصوصة أو غير واضحة، وبعض الأقسام كانت تظهر بحرف فقط لأن القسم نفسه لا يملك صورة. المطلوب أن تظهر مثل واجهات التطبيقات الاحترافية: صورة واضحة مكتملة، اختصارات للمجموعات، وشاشة متجر أجمل للمتسوق.

---

## ما تم تنفيذه

### 1) توليد صورة معاينة للقسم تلقائياً
تم تعديل:

```txt
components/store/storefront-experience.tsx
```

الآن إذا كان القسم لا يملك صورة، يأخذ النظام صورة أول منتج داخل القسم كصورة معاينة للقسم.

يعني:

```txt
قسم ملابس رجالية
```

إذا لم توجد له صورة مباشرة، سيظهر بصورة أحد منتجاته مثل الجاكيت/القميص بدلاً من حرف فقط.

---

### 2) منع قص الصور داخل الأصناف
تم تغيير عرض صور الأقسام والمنتجات من:

```txt
object-cover
```

إلى:

```txt
object-contain
```

في المواضع المناسبة، حتى تظهر الصورة كاملة بدون قص.

---

### 3) تصميم اختصارات المجموعات بشكل بطاقات تطبيق
تم تغيير شريط مجموعات المتجر من شريط صغير بأيقونة/حرف إلى بطاقات أوسع مثل تطبيق متجر:

- صورة كاملة واضحة.
- اسم المجموعة.
- عدد المنتجات داخل المجموعة.
- تأثير hover.
- سحب أفقي على الجوال.

النص أصبح:

```txt
اختصارات مجموعات المتجر
صور كاملة وواضحة — اسحب الشريط أو اضغط لتصفية المنتجات
```

---

### 4) تحسين أقسام التوصيات الذكية
قسم:

```txt
أقسام مقترحة لك
```

أصبح يعرض صورة القسم/أول منتج داخله بشكل كامل وواضح بدلاً من الاقتصاص.

---

### 5) تحسين صور المنتجات في كروت المتجر
تم تعديل كروت المنتجات داخل واجهة المتجر بحيث تعرض صورة المنتج كاملة قدر الإمكان داخل الإطار، وهذا مناسب خصوصاً للأزياء والأحذية والأدوات المنزلية.

---

### 6) تحسين لوحة واجهة المتجر
تم تقليل عتامة طبقة التغطية على صورة لوحة المتجر الرئيسية حتى تظهر صورة المتجر أو الإعلان بشكل أوضح، مع إبقاء النص قابلاً للقراءة.
