# تصميم تنفيذ نموذج إيرادات المنصة الموحد

**التاريخ:** 14 يوليو 2026  
**القاعدة:** لا إضافة بدون حساب التوسع، ولا إضافة بدون حساب الصيانة.

## القرار التجاري المنفذ

المنصة **ليست وسيطاً مالياً لمبيعات العملاء**. أموال طلب العميل تذهب للتاجر أو إلى بوابة/حساب التاجر فقط. إيراد المنصة محصور في:

1. إيجار شهري ثابت.
2. عمولة مبيعات شهرية بحسب نموذج التاجر المحدد بالعقد وتقرير مبيعات معتمد.
3. إعلانات وظهور مميز، ضمن اتفاق ترويج منفصل عن عقد الإيجار.

يسمح الأدمن لكل متجر باختيار أحد النماذج:

```text
monthly_rent       = إيجار فقط
sales_commission   = نسبة مبيعات فقط
hybrid             = إيجار + نسبة مبيعات
```

## النطاق

- شروط إيراد منصة مستقلة لكل متجر (`merchant_revenue_terms`) مرتبطة اختيارياً بالعقد القانوني.
- اتفاق ترويج مستقل (`merchant_promotion_agreements`) لرسوم الواجهة الرئيسية والمنتجات/المتاجر المميزة.
- تقرير مبيعات شهري من التاجر، مع اعتماد/رفض أدمن وسجل تدقيق.
- كشف/فاتورة موحدة واحدة لكل متجر ولكل شهر، تضم rent + commission + advertising + addons.
- إثبات سداد وقرار أدمن فقط لإيراد المنصة.
- دورة overdue / grace / تعليق متجر وإعلانات بعد المهلة، بلا لمس لأموال العميل أو رصيد التاجر.

## خارج النطاق

- لا خصم من بطاقة العميل أو محفظته لصالح المنصة.
- لا احتفاظ بمبيعات العميل ولا payout للتاجر ضمن هذه الدورة.
- لا تحصيل خارجي حي أو فاتورة ضريبية قانونية دون مزود مالي وسياسة قانونية معتمدة.
- لا تقبل المنصة تقرير API خارجي غير موثق في هذه الحزمة؛ يبقى مدخل API مهيأً للمرحلة التالية بعد اختيار موفر ERP/توقيع التكامل.

## تصميم البيانات

```text
merchant_revenue_terms
  model, monthly_rent, commission_rate, due_days, grace_days,
  start/end, status, contract snapshot/version

merchant_promotion_agreements
  منفصل عن الإيجار، رسوم homepage banner / featured product / featured store

merchant_sales_reports
  period, declared total, source, status, reviewer, audit metadata

merchant_platform_statements
  كشف موحد store/month مع حالة وسداد ومهلة

merchant_platform_statement_lines
  rent / commission / advertising / addon / adjustment
  مع sourceType + sourceId لمنع التكرار والتدقيق
```

## تسلسل التشغيل

```text
الأدمن يضبط شروط الإيراد + اتفاق الترويج
      ↓
التاجر يبيع ويستلم المال مباشرة
      ↓
نهاية الشهر: يرفع التاجر تقرير مبيعات
      ↓
الأدمن يعتمد/يرفض التقرير
      ↓
Job موحد يصدر statement واحداً:
  الإيجار + (المبيعات المعتمدة × العمولة) + فواتير الإعلانات + الإضافات
      ↓
التاجر يحول للمنصة أو يرفع إثبات سداد
      ↓
الأدمن يعتمد السداد
      ↓
إذا انتهت المهلة: overdue → grace → freeze store + pause ads
```

## التوسع Scalability

- مفتاح فريد `store + period` يمنع فاتورة موحدة مكررة في إعادة cron.
- خطوط الفاتورة مصدرية (`source_type/source_id`) ومفهرسة لمنع إدراج نفس فاتورة الإعلان/الإضافة مرتين.
- توليد البيان في transaction مع advisory lock لكل متجر/فترة، وليس قفلاً عاماً.
- تجميع تقارير المبيعات والإعلانات محكوم بفترة زمنية وفهارس store/status/period.
- worker يعالج دفعات محددة قابلة للإعادة ولا يمس بيانات مبيعات العملاء.

## الصيانة والمراقبة

- **Owner:** Finance / Collections admin مع صلاحيات منفصلة للشروط والتقارير والتسوية.
- Audit لكل تغيير شروط، رفع تقرير، مراجعة، إصدار كشف، إثبات سداد، تعليق وإعادة تفعيل.
- Cron شهري للإصدار، وcron يومي لمراقبة overdue/grace؛ كلاهما idempotent.
- تنبيه/Work Queue عند تقرير مبيعات ينتظر مراجعة، كشف مستحق، أو متجر عُلّق بسبب الإيراد.
- لا يوجد اتصال مباشر بقاعدة ERP أو مزود مالي؛ التكامل لاحقاً عبر API/queue/DLQ.

## التوافق والـrollback

- migrations additive فقط.
- الفوترة القديمة للإيجار والإعلان تبقى قابلة للقراءة؛ المتجر لا يدخل دورة البيان الموحد إلا عند تفعيل `merchant_revenue_terms`.
- عند تفعيل الشروط الموحدة، تمنع خدمة الإيجار إصدار فاتورة إيجار مستقلة للمتجر لتفادي الازدواج.
- التراجع التشغيلي: إيقاف terms الموحدة يعيد المتجر إلى legacy billing بعد مراجعة مالية؛ لا يحذف الفواتير أو القيود.
- إعادة تنشيط متجر لا تتم إلا إذا لم توجد بيانات revenue overdue أخرى، ولا تمس تعليقاً لأسباب أمنية/إدارية أخرى.

## الاختبارات المطلوبة

- اختيار النموذج rent/commission/hybrid.
- statement rent only، commission only، hybrid.
- منع statement أو line مكرر.
- منع إصدار commission بدون sales report معتمد.
- settlement وoverdue/grace/freeze policy.
- فصل اتفاق الترويج ورسوم homepage عن عقد الإيجار.
