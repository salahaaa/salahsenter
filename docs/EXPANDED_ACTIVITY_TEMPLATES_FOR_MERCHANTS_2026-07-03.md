# تقرير توسيع قوالب النشاطات للتجار — 2026-07-03

## الهدف
توسيع القوالب الذكية في شاشة إعدادات الأصناف والمتغيرات لتشمل نشاطات أكثر مثل المواد الغذائية والتموين وغيرها، بحيث يستطيع التاجر تجهيز متجره بضغطة واحدة حسب نوع النشاط.

---

## ما تم تنفيذه
تم تحديث:

```txt
components/merchant/product-taxonomy-form.tsx
```

وتم توسيع القوالب الذكية لتشمل نشاطات إضافية مع:

- أقسام مناسبة.
- وحدات بيع مناسبة.
- مقاسات/أحجام مناسبة.
- ألوان مناسبة عند الحاجة.
- متغيرات وقيم متغيرات جاهزة.
- كلمات مفتاحية لاكتشاف النشاط واقتراح القالب تلقائياً.

## تحسين الاقتراح التلقائي
تم توسيع الكلمات المفتاحية حتى يقترح النظام القالب المناسب عند قراءة اسم ووصف المتجر والأقسام الحالية.

أمثلة:

- إذا كتب التاجر: مواد غذائية، تموين، أرز، زيوت، معلبات → يظهر قالب مواد غذائية وتموين.
- إذا كتب: خضار، فواكه، ورقيات → يظهر قالب خضار وفواكه.
- إذا كتب: مخبز، كيك، حلويات، معجنات → يظهر قالب مخبز / حلويات.
- إذا كتب: لحوم، دجاج، أسماك → يظهر قالب لحوم / دواجن / أسماك.
- إذا كتب: ألبان، حليب، أجبان → يظهر قالب ألبان وأجبان.
- إذا كتب: مشروبات، مياه، عصائر، قهوة → يظهر قالب مشروبات ومياه.
