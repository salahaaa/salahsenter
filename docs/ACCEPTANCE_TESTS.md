# اختبار القبول النهائي — دورة فتح المتجر والعقد الإلكتروني

لا تعتبر دورة فتح المتجر مكتملة إلا بعد نجاح جميع الاختبارات التالية بالترتيب.

## 1) تقديم الطلب

1. الدخول إلى `/apply-store`.
2. تعبئة بيانات مقدم الطلب والمتجر والجناح والموقع ووسائل التواصل.
3. إرسال الطلب.
4. يجب أن تظهر رسالة نجاح ورابط: **فتح العقد للتوقيع**.
5. يجب أن يتم إنشاء سجل في `merchant_applications` بحالة `new`.

## 2) إنشاء العقد وعرضه للطالب

1. فتح `/apply-store/{applicationId}/contract`.
2. يجب عرض بيانات الطلب: اسم المتجر، مقدم الطلب، النشاط، حالة الطلب.
3. يجب عرض نص العقد الافتراضي أو النص المحفوظ في قاعدة البيانات.
4. يجب ألا يتم إنشاء أو تفعيل متجر في هذه المرحلة.

## 3) توقيع العميل إلكترونياً

1. كتابة اسم الموقّع.
2. التوقيع داخل مربع التوقيع الإلكتروني.
3. تحديد الموافقة على العقد.
4. الضغط على حفظ العقد والتوقيع.
5. يجب حفظ:
   - `contract_accepted_at`
   - `contract_signature_data_url`
   - `signed_contract_snapshot`
6. يجب تغيير حالة الطلب إلى `waiting_final_approval`.
7. يجب ألا يتم إنشاء المتجر أو تفعيله بعد التوقيع مباشرة.

## 4) مراجعة الأدمن

1. الدخول إلى `/admin/merchant-applications`.
2. فتح صفحة مراجعة الطلب `/admin/merchant-applications/{id}`.
3. يجب أن تظهر:
   - جميع بيانات الطلب.
   - العقد المحفوظ.
   - صورة التوقيع الإلكتروني.
   - حالة: بانتظار الموافقة النهائية من الأدمن.
4. إذا حاول الأدمن الموافقة قبل التوقيع يجب أن تفشل العملية برسالة واضحة.

## 5) الموافقة النهائية

عند ضغط **موافقة نهائية** يجب تنفيذ التالي تلقائياً:

1. ترقية حساب مقدم الطلب بإضافة دور `merchant`.
2. إنشاء/تحديث سجل في جدول `merchants`.
3. إنشاء متجر جديد في `stores`.
4. إنشاء رقم متجر فريد `store_number` غير قابل للتكرار.
5. ربط المتجر بالجناح المعتمد داخل `store_wings`.
6. تفعيل المتجر مباشرة:
   - `stores.status = active`
   - `stores.is_active = true`
7. إنشاء كلمة مرور مؤقتة وتعيين `users.must_change_password = true`.
8. تغيير حالة الطلب إلى `approved` وحفظ `final_approved_at` و `final_approved_by`.

## 6) الإشعارات وبيانات الدخول

بعد الموافقة يجب إنشاء إشعار في `notifications` يحتوي على:

- رقم المتجر.
- اسم المستخدم.
- كلمة المرور المؤقتة.
- حالة الاعتماد.
- تاريخ التفعيل.

إذا كانت الخدمات مفعلة عبر:

```env
EMAIL_NOTIFICATIONS_ENABLED=true
SMS_NOTIFICATIONS_ENABLED=true
```

فيجب استدعاء نقطة التكامل الخاصة بالإرسال الخارجي.

## 7) تسجيل دخول التاجر

يجب أن يستطيع التاجر تسجيل الدخول بطريقتين:

1. البريد الإلكتروني + كلمة المرور المؤقتة.
2. رقم المتجر + كلمة المرور المؤقتة.

بعد الدخول يجب أن يستطيع تغيير كلمة المرور من `/merchant/settings`.

## 8) قيود التعديل

- لا يستطيع التاجر تعديل رقم المتجر.
- لا يستطيع التاجر تعديل اسم المتجر.
- تعديل رقم المتجر أو اسم المتجر يكون من خلال الأدمن فقط وفق الصلاحيات.

## 9) ظهور المتجر للمتسوقين

بعد التفعيل يجب التحقق من:

1. ظهور المتجر في `/api/stores`.
2. فتح صفحة المتجر `/store/{slug}` بدون أخطاء.
3. ارتباط المتجر بالجناح الصحيح.
4. ظهور المنتجات النشطة التابعة للمتجر للمتسوقين.
5. ظهور الصور والأسعار والتفاصيل بدون تأخير أو مشاكل.

## 10) معيار النجاح النهائي

تعتبر الدورة ناجحة فقط عند اكتمال جميع المراحل التالية:

تقديم الطلب → إنشاء العقد → توقيع العميل → مراجعة الأدمن → الموافقة النهائية → ترقية العميل إلى تاجر → إنشاء سجل التاجر → تفعيل المتجر → إرسال بيانات الدخول → تسجيل دخول التاجر بالبريد أو رقم المتجر → ظهور المتجر ومنتجاته فعلياً للمتسوق.
