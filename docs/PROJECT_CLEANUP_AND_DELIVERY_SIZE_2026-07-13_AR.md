# تقرير تنظيف المشروع وحجم التسليم

**التاريخ:** 2026-07-13

## ما تمت إزالته

| العنصر | الحجم قبل الحذف | السبب |
|---|---:|---|
| `node_modules/` | 874 MB | اعتماديات محلية قابلة لإعادة الإنشاء بالكامل عبر `npm ci` ولا يجب تضمينها في ملف تسليم المشروع. |
| `tsconfig.tsbuildinfo` | 580 KB | ملف TypeScript incremental مؤقت ومهمل في Git. |
| `.config/nextjs-nodejs/config.json` | صغير | ملف Telemetry محلي خاص ببيئة التطوير، ليس جزءاً من مصدر المنصة. |

كما تم تحديث `.gitignore` لمنع إعادة إضافة `.config/` محلياً.

## ما تم الاحتفاظ به عمداً

- `drizzle/meta/` (~4.7 MB): snapshots تاريخ migration؛ الاحتفاظ بها يحمي توافق Drizzle والتحقق من migration history.
- `docs/` (~1 MB): أدلة التشغيل والتقارير وسجل القرارات.
- `.git/` (~5.7 MB): تاريخ المستودع المحلي؛ لم يحذف لتجنب فقدان التتبع والاسترجاع.
- `package-lock.json`: ضروري لإعادة تثبيت نسخ الاعتماديات نفسها بشكل قابل للتكرار.

## الحجم بعد التنظيف

| القياس | الحجم |
|---|---:|
| مجلد المشروع شاملاً `.git` | **20 MB** تقريباً |
| مصدر التسليم بدون `.git` وبدون الاعتماديات | **15 MB** تقريباً |
| تقدير أرشيف source مضغوط (`tar.gz`) بدون `.git` | **1.5 MB** تقريباً |

تم تحرير حوالي **874 MB** من المساحة المحلية، أي تقليل يقارب **97%** من حجم مجلد العمل قبل التنظيف.

## لإعادة تشغيل التطوير

لا توجد `node_modules` بعد التنظيف، وهذا مقصود. أعد تثبيتها عند الحاجة فقط:

```bash
npm ci
npm run dev
```

لا توجد ملفات Media أو Backups أو logs أو build artifacts كبيرة داخل مصدر المشروع بعد التنظيف.
