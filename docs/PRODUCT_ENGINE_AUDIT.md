# Product Engine Audit & Implementation

## نتيجة الفحص قبل التنفيذ

النظام السابق كان يدعم منتجات بسيطة ومتغيرات أولية فقط. كان يفتقد إلى:

- خصائص ديناميكية ينشئها التاجر.
- توليد تركيبات المتغيرات تلقائياً.
- تصنيفات هرمية بأكواد تلقائية/يدوية.
- بيانات المنتج المتقدمة.
- صور متعددة وصور مرتبطة بالمتغيرات.
- صفحة عرض منتج احترافية.
- مواصفات وأسئلة وأجوبة.

## ما تم تنفيذه

### 1) إعدادات الأصناف والمتغيرات

صفحة جديدة:

```txt
/merchant/product-taxonomy
```

تدعم:

- مجموعات وأقسام هرمية مفتوحة.
- كود تلقائي أو يدوي للقسم.
- خصائص ديناميكية مثل اللون، المقاس، السعة، المادة، الرائحة.
- قيم الخصائص مع كود ولون HEX وصورة اختيارية.
- إدارة الوحدات والمقاسات والألوان من نفس السياق.

API:

```txt
/api/merchant/product-taxonomy
```

### 2) محرك إضافة المنتج

تم استبدال شاشة المنتج القديمة بمحرك جديد في:

```txt
/merchant/products
```

يدعم:

- اسم عربي وإنجليزي.
- كود تلقائي حسب التصنيف أو كود يدوي.
- باركود.
- وصف مختصر وتفصيلي.
- علامة تجارية.
- بلد المنشأ.
- ضمان.
- رابط يوتيوب.
- صور متعددة.
- مواصفات ديناميكية بصيغة `الاسم = القيمة`.
- سعر أساسي.
- سعر مستقل أو فرق سعر للمتغير.
- مخزون عام أو لكل متغير.
- اختيار خصائص وقيم وتوليد كل التركيبات تلقائياً.

### 3) المتغيرات الاحترافية

لكل Variant:

- SKU.
- باركود.
- عنوان تلقائي من الخصائص.
- سعر.
- Compare At Price.
- Price Adjustment.
- كمية مخزون.
- حد تنبيه قرب النفاد.
- صورة.
- خصائص JSON.
- ربط جدولي بقيم الخصائص.

### 4) صفحة عرض المنتج

صفحة جديدة:

```txt
/store/[slug]/products/[productSlug]
```

تحتوي على:

- معرض صور.
- صور مصغرة.
- تقييم وعدد مراجعات وعدد مشاهدات.
- السعر والخصم.
- اختيار المتغيرات.
- أزرار إضافة للسلة وشراء الآن ومفضلة ومشاركة وواتساب.
- الوصف.
- المواصفات.
- السياسات.
- بيانات المتجر.

### 5) الجداول الجديدة

```txt
product_attributes
product_attribute_values
product_variant_attribute_values
product_images
product_specifications
product_questions
product_answers
```

### 6) تطوير الجداول الحالية

`categories`:

- `code`
- `code_mode`
- `level`

`products`:

- `english_name`
- `product_code`
- `code_mode`
- `barcode`
- `short_description`
- `brand`
- `origin_country`
- `warranty`
- `youtube_url`
- `specifications`
- `pricing_mode`
- `inventory_mode`
- `discount_percent`

`product_variants`:

- `barcode`
- `compare_at_price`
- `price_adjustment`
- `images`
- `attributes`

كما تم جعل SKU فريداً على مستوى المنتج بدلاً من المنصة كاملة.

## معيار القبول

النظام الآن يدعم من شاشة واحدة بيع:

- أحذية.
- ملابس.
- شاشات.
- جوالات.
- أثاث.
- مواد غذائية.
- مواد بناء.
- أدوات منزلية.
- عطور.
- صيدليات.

بدون تعديل برمجي مستقبلي، عبر خصائص ومتغيرات ديناميكية.
