# تقرير تنفيذ: Merchant Operations Center

**التاريخ:** 2026-07-15
**الحالة:** مكتمل محلياً ومتحقق آلياً.

## ما تم تطويره

### المتجر النشط
- أضيف Store Switcher داخل Hero لوحة التاجر.
- يعرض كل المحلات/الفروع التي يملكها الحساب ويستخدم endpoint الحالي المراجع للصلاحية لتحديث `merchant_store_id`.
- بعد التبديل تعاد قراءة dashboard scoped للمتجر المختار؛ لا تختلط طلبات أو مخزون أو منتجات المتاجر.

### محفظة المتاجر
- أضيف ملخص: عدد المتاجر، المتاجر النشطة، والمبيعات المخزنة عبر المحفظة.
- تظهر بطاقات المتاجر وأرقامها وحالتها، مع رابط لإدارة المحلات والفروع.

### الالتزامات المالية
- أضيف ملخص لكشوف إيرادات المنصة المفتوحة للمتجر النشط وللمحفظة، وعدد الكشوف وموعد الاستحقاق الأقرب.
- تجمع المبالغ حسب العملة، ولا تخلط YER/SAR/USD في رقم واحد.
- النص يوضح أنها التزامات منصة فقط وليست أموال مبيعات العملاء.

### الأدوات
- أدوات التشغيل والكتالوج تظهر مباشرة.
- المجموعة الكبيرة للتسويق والإدارة المتقدمة أصبحت collapsed تحت «أدوات متقدمة»، فتقل ازدحام اللوحة دون حذف أي وظيفة أو رابط.
- بقيت قائمة عمل اليوم والجاهزية والتنبيهات والعقد والإشعارات في واجهة الأولوية.

## الحوكمة والتوافق
- لا migration أو table جديد.
- لا تغيير في RBAC أو منح صلاحيات من روابط dashboard؛ الصفحات وAPIs النهائية تبقى الحارس.
- لا تغيير مالي أو payout/settlement.
- حساب المتجر الواحد يرى نفس dashboard مع selector بسيط، والحساب متعدد المتاجر يرى المحفظة.
