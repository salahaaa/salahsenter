## الحزم

لا توجد حزم مفقودة. توجد حزم يمكن ترقيتها لاحقاً مثل:

- next 15.5.18 -> 15.5.19 أو 16.x مستقبلاً.
- eslint 8 -> 10 مستقبلاً.
- react 18 -> 19 مستقبلاً بعد اختبار التوافق.
- zod 3 -> 4 مستقبلاً بعد تعديل الكود.

## ملاحظات أمنية متبقية

ليست مانعة للبناء أو النشر، لكنها مهمة للإنتاج التجاري:

1. إضافة Rate Limiting لمسارات login/register/upload/contract.
2. إضافة CSRF أو Origin validation للطلبات التي تعدل البيانات.
3. تطبيق RBAC permissions الدقيقة داخل كل API.
4. عدم تخزين كلمة المرور المؤقتة داخل notifications لفترة طويلة أو تشفيرها.
5. فحص magic bytes للملفات المرفوعة.
6. نقل النسخ الاحتياطية إلى S3/R2 في الإنتاج.
7. تحسين unique constraints مثل user_roles مع storeId null.
8. إضافة اختبارات E2E آلية لدورة فتح المتجر ودورة المنتج والطلب.
