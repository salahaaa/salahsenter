# تقرير تنفيذ: مراجعة إصلاح استيراد المنتجات بالذكاء الاصطناعي — مسار آمن

**التاريخ:** 2026-07-15  
**الحالة:** مكتمل محلياً ومتحقق آلياً.

## ما تم تنفيذه

### 1) واجهة مراجعة قبل الحفظ
- أضيفت لوحة **«خطة إصلاح قبل الحفظ»** ضمن صفحة التاجر `/merchant/smart-tools` بعد معاينة ملف Excel/CSV.
- ترسل اللوحة الحقول اللازمة من المسودات الحالية فقط إلى مسار المنصة، ثم تعرض:
  - عدد الصفوف المحللة والجاهزة وتلك التي تحتاج إدخالاً بشرياً.
  - المشكلة في كل صف (مثل السعر المفقود أو المخزون غير الصحيح).
  - SKU مقترح، ومرجع باركود داخلي، وخيارات variants مقترحة، وعبارة بحث لتصنيف المنتج.
- تعرض الواجهة أول 100 نتيجة فقط، مع بقاء الملخص محسوباً على كل الصفوف، لحماية سلاسة المتصفح.

### 2) مسار API آمن وقابل للصيانة
- حُوّل منطق بناء الخطة إلى `lib/ai/import-repair.ts` ليكون نقياً وقابلاً للاختبار.
- يدعم API الحالي كلا المسارين:
  - `{ rows }` لمسودات المعاينة غير المحفوظة — وهو المسار الذي تستخدمه الواجهة الجديدة.
  - `{ runId }` للتوافق مع الاستعمال السابق.
- الحد الصارم للخطة: **1000 صف** في الطلب الواحد.
- أضيف تحقق وصول المتجر وصلاحية `ai.use` قبل التحليل.

### 3) ضمانات الحوكمة
- لا تنشئ الميزة منتجاً أو تعدل مسودة أو تحفظ قاعدة بيانات تلقائياً.
- لا تنشر منتجاً، ولا تغيّر السعر أو المخزون أو حالة النشر أو أي قيد مالي.
- السعر أو المخزون الناقصان يظهران كمشكلة ولا تُخترع لهما قيمة.
- الباركود المقترح معلن بوضوح كـ **مرجع داخلي فقط، وليس GS1/EAN**.
- لا تُرسل بيانات الاستيراد إلى OpenAI أو Gemini أو أي مزود خارجي؛ هذا التحليل قواعدي محلي داخل المنصة.

## قرار أمني متعمد
تم **تأجيل واجهة رفع/قراءة فاتورة المورد**. التخزين الإعلامي الحالي قد يكون محلياً أو عاماً، ولا يضمن خصوصية فواتير المورد في بيئة Production. يلزم أولاً:
1. تخزين S3/R2 خاص؛
2. روابط تنزيل موقعة أو Proxy محمي؛
3. سياسة احتفاظ وتدقيق وصول؛
4. مراجعة خصوصية لمزود OCR/Vision.

لذلك لم يُفتح أي مسار جديد لرفع ملفات حساسة.

## التوسع والصيانة
- الخطة محددة بـ1000 صف وعرضها محدود بـ100 صف؛ لا توجد queue أو عملية خلفية أو كتابة بيانات.
- زمن التحليل خطي O(n) ضمن حد معروف؛ لا يضيف migrations أو cache أو storage.
- حد الاستيراد التشغيلي الحالي لقراءة/حفظ الملف ما زال 500 صف؛ رفعه يحتاج قياس أداء ومعالجة دفعات/queue مستقلة، ولم يتم تجاوزه بلا دراسة.
- لا يوجد أثر على API قائم أو البيانات أو الترحيلات، ويمكن التراجع بحذف اللوحة وفرع `{ rows }` فقط.
