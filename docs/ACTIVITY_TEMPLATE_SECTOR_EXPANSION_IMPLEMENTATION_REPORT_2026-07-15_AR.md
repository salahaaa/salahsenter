# تقرير تنفيذ: توسعة قطاعات قوالب نشاط التاجر

**التاريخ:** 2026-07-15
**الحالة:** مكتمل محلياً ومتحقق آلياً.

## التوسعة
القوالب القائمة للأثاث والأدوات المنزلية بقيت، وأضيفت قطاعات أدق:
```text
أجهزة منزلية وكهربائية
ديكور وسجاد وستائر
أقمشة وخياطة وتفصيل
جوالات وملحقات وصيانة
كمبيوتر وألعاب وملحقات
ذهب ومجوهرات وإكسسوارات
زراعة وري وبذور
جملة وتوزيع وتجارة عامة
```

لكل قالب أقسام ووحدات وخصائص وقيم متغيرات، وليس مجرد اسم في قائمة.

## التوصية والمعاينة
- أضيفت keywords لكل قطاع كي تظهر توصية تلقائية من اسم ووصف المتجر.
- تستمر القائمة المستطيلة مع المعاينة قبل التطبيق.
- تحذيرات خاصة للذهب والزراعة بالإضافة إلى الصيدلية والخدمات، حتى لا يوهم القالب التاجر بوجود تسعير ذهب أو توصيات زراعية أو وصفات/حجوزات تلقائية.

## الحوكمة
- لا ينشئ القالب منتجات أو مخزوناً أو أسعاراً أو التزامات مالية.
- التطبيق upsert ولا يحذف taxonomy قائم.
- لا migration أو queue جديدة.
