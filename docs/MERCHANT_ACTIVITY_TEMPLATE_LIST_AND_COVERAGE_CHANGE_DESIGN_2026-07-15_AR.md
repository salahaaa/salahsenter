# تصميم تغيير: قوالب نشاط التاجر — قائمة مستطيلة ومعاينة وتغطية قطاعية

**التاريخ:** 2026-07-15

## المشكلة
القوالب الحالية تظهر كمربعات قابلة للنقر وتطبق مباشرة بعد confirm. لا تعرض للتاجر تفاصيل كافية قبل التطبيق، ولا تميز بين القالب الذي يجهز taxonomy فقط وبين نظام قطاعي كامل. كما أن تغطية القطاعات تحتاج توسعة.

## القرار
- استبدال grid cards بقائمة مستطيلة قابلة للاختيار مع معاينة جانبية/سفلية.
- التطبيق لا ينشئ منتجات أو مخزوناً أو أسعاراً أو قيوداً مالية.
- يعرض القالب بالضبط: الأقسام، الوحدات، الخصائص، المقاسات والألوان.
- يضيف تأكيداً صريحاً داخل الواجهة بدلاً من نافذة browser confirm.
- توسعة القوالب: مواد بناء/أدوات، قطع غيار سيارات، قرطاسية وكتب، أطفال وألعاب.
- تحذيرات قطاعية: الصيدلية والخدمات لا تحصل تلقائياً على نظام وصفات/حجوزات من هذا القالب.

## السلامة والصيانة
- API يظل idempotent/upsert، ولا يحذف taxonomy قائم.
- يضيف API fields وصفية فقط للمعاينة، لا أسرار ولا معلومات حساسة.
- template data ثابت ومراجع باختبارات، ويمكن لاحقاً نقل catalog إلى DB مع versioning دون كسر العقد.
- لا migration أو queue جديدة.
