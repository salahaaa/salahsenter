# تقرير معالجة ملاحظات نظام العروض

التاريخ: 2026-07-02

## الملاحظات التي تمت معالجتها

### 1) إزالة قائمة أفضل المنتجات

تم حذف ظهور لوحة "أفضل المنتجات" من لوحة التاجر حتى لا تزاحم لوحة الإعدادات والتشغيل.

الملف:

```txt
components/merchant/merchant-dashboard-pro.tsx
```

### 2) العرض المجمع يجب أن يحتوي أكثر من منتج

تم فرض ذلك في الواجهة والـ API:

- إذا اختار التاجر نوع "عرض مجمع" يجب اختيار منتجين على الأقل.
- الـ API يرفض العرض المجمع بمنتج واحد.

الملفات:

```txt
components/merchant/store-offer-form.tsx
lib/validators.ts
```

### 3) اختيار المنتجات أصبح جدولاً قابلاً للبحث

بدلاً من بطاقات كبيرة، أصبح اختيار منتجات العرض في جدول مناسب لآلاف المنتجات، مع بحث عبر:

- رقم الصنف.
- اسم الصنف.
- الباركود.

الأعمدة:

- اختيار.
- رقم الصنف.
- اسم الصنف.
- السعر الأساسي.
- سعر عرض خاص للمنتج.
- الحالة.

الملف:

```txt
components/merchant/store-offer-form.tsx
```

كما تم رفع تحميل المنتجات في صفحة عروض التاجر إلى 1000 منتج بدلاً من 80.

### 4) عرض منتج واحد يستخدم صورة المنتج تلقائياً

إذا كان العرض لمنتج واحد:

- لا تظهر خانة رفع صورة العرض في الواجهة.
- يتم استخدام صورة المنتج تلقائياً.

الملفات:

```txt
components/merchant/store-offer-form.tsx
app/api/merchant/offers/route.ts
```

### 5) اختيار الخصم: نسبة أو مبلغ

تم دمج حقلي النسبة والمبلغ في واجهة واحدة:

- طريقة الخصم: مبلغ / سعر عرض.
- طريقة الخصم: نسبة %.

بدلاً من عرض خانتين في نفس الوقت.

### 6) طريقة النشر لم تعد بيد التاجر

تم حذف اختيار "نشر مباشر أو موافقة الأدمن" من واجهة التاجر.

الآن التاجر يرسل العرض للمعالجة، وسياسة النشر والاعتماد تكون بيد الإدارة.

الملفات:

```txt
components/merchant/store-offer-form.tsx
app/api/merchant/offers/route.ts
```

### 7) بداية ونهاية العرض أصبحت إلزامية

تم فرض:

- بداية العرض.
- نهاية العرض.
- نهاية العرض يجب أن تكون بعد البداية.

في الواجهة والـ API.

### 8) منع تكرار العرض في عدة أقسام في صفحة العروض

تمت إعادة تنظيم صفحة `/offers` بحيث يظهر كل عرض في قسم واحد فقط.

الأقسام:

- عروض اليوم.
- الحصرية.
- الرائجة.
- الجديدة.
- عروض أخرى من المتاجر.
- عروض الإدارة.

الملف:

```txt
app/offers/page.tsx
```

### 9) نوافذ الأقسام أصبحت قابلة للدخول عند وجود عروض

بطاقات:

- عروض اليوم.
- الحصرية.
- الرائجة.
- الجديدة.
- عروض المتاجر.
- عروض الإدارة.

أصبحت روابط anchor إلى القسم المناسب إذا كان يحتوي عروضاً.

### 10) إشعارات العميل والتاجر عند الشراء

تم تعديل إنشاء الطلب ليضيف إشعارات داخلية مباشرة داخل transaction:

- إشعار للعميل: تم إنشاء طلبك بنجاح.
- إشعار للتاجر: طلب جديد بانتظار المراجعة.

ولم تعد هذه الإشعارات تعتمد فقط على background jobs.

الملف:

```txt
app/api/orders/route.ts
```

كما تم تعديل معالج jobs حتى لا يكرر إشعار التاجر لاحقاً.

الملف:

```txt
lib/queue/processor.ts
```
