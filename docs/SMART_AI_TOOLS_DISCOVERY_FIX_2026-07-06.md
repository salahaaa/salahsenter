# تقرير إظهار الإضافات الذكية للتاجر والأدمن — 2026-07-06

## سبب المشكلة
بعد فحص النسخة المنشورة والكود، تبيّن أن بعض أدوات الذكاء موجودة لكنها كانت موزعة داخل صفحات مختلفة وليست مجمعة بوضوح، مثل:

- تجهيز العروض داخل `/merchant/offers`.
- وصف المنتج والمتغيرات داخل `/merchant/products`.
- منصة الإعلانات داخل `/merchant/ads`.
- مساعد الأدمن لتلخيص طلبات فتح المتاجر داخل صفحة تفاصيل الطلب.
- مساعد مراجعة الإعلانات داخل صفحة الإعلانات.
- مراقبة المنصة داخل Observability/Security.

لذلك كان من السهل ألا يراها المستخدم رغم وجود أجزاء منها.

## ما تم تنفيذه الآن

### 1) مركز واضح لأدوات التاجر الذكية
تم إضافة مكون جديد:

```txt
components/merchant/merchant-smart-launchpad.tsx
```

وتم إظهاره داخل:

```txt
/merchant/smart-tools
```

يعرض بطاقات واضحة لـ:

- تجهيز عرض ذكي.
- تجهيز بنر إعلان.
- وصف المنتج والمتغيرات.
- قوالب نشاط المتجر.
- المساعد التجاري اليومي.
- الإعداد الذكي للمتجر.

### 2) تجهيز بنرات الإعلانات للتاجر
تم تطوير مساعد خاص داخل صفحة:

```txt
/merchant/ads
```

المساعد الجديد يجهز:

- اسم الحملة.
- عنوان الإعلان.
- وصف الإعلان.
- CTA.
- الكلمات المفتاحية.
- فكرة التصميم.
- ألوان مقترحة.
- Preview بصري داخل النموذج.
- قائمة مراجعة قبل الإرسال.

مع الالتزام بعدم حفظ صور `base64` داخل قاعدة البيانات.

الملفات الجديدة:

```txt
lib/ai/ad-banner-suggester.ts
app/api/merchant/ad-campaigns/ai-banner/route.ts
```

### 3) مركز واضح لإضافات الأدمن الذكية
تم إنشاء صفحة جديدة:

```txt
/admin/ai-tools
```

تجمع أدوات الأدمن الذكية في مكان واحد:

- تلخيص طلبات فتح المتاجر.
- مراجعة إعلانات المتاجر.
- مساعد مراقبة المنصة.
- مركز حماية المنصة الذكي.
- مراجعة العروض الموسمية.
- إدارة جاهزية المتاجر.

وتمت إضافة بطاقة لها في لوحة الأدمن الرئيسية.

### 4) تحديث لوحة الأدمن
تم تعديل:

```txt
app/admin/page.tsx
```

لإظهار بطاقة:

```txt
مركز إضافات الأدمن الذكية
```

### 5) تحديث صفحة الإضافات الذكية للتاجر
تم تعديل:

```txt
app/merchant/smart-tools/page.tsx
```

لتصبح الصفحة مركزاً واضحاً لكل أدوات الذكاء، وليس فقط إضافة منتجات.

## ملاحظات عن النسخة المنشورة
الروابط الذكية الأساسية على Vercel موجودة وتحوّل لتسجيل الدخول عند عدم وجود جلسة، مثل:

```txt
/merchant/smart-tools
/merchant/ai-assistant
/merchant/offers
/merchant/ads
/admin/merchant-applications
/admin/ads
```

لكن التحسينات الجديدة في هذا التقرير لن تظهر على المنصة إلا بعد عمل Deploy جديد من آخر كود.

## المطلوب بعد النشر
بعد Deploy جديد، ستظهر الأدوات في:

```txt
/merchant/smart-tools
/merchant/ads
/admin/ai-tools
/admin
```

ولا تحتاج هذه الإضافات إلى migration جديدة لأنها تعتمد على الجداول الحالية.
