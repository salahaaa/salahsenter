# تقرير المرحلة الأولى من بناء دور الذكاء الاصطناعي — مساعد العروض الذكي للتاجر

## الهدف
بدء تنفيذ مراحل الذكاء الاصطناعي بشكل عملي، بدءاً بأكثر نقطة مفيدة حالياً: مساعدة التاجر في إنشاء العروض المجمعة بناءً على وصف طبيعي.

## ما تم تنفيذه

### 1) محرك اقتراح عروض مجمعة
تم إنشاء:

```txt
lib/ai/merchant-bundle-suggester.ts
```

يدعم:
- تحليل نص عربي مبسط.
- فهم كميات مثل: 3، ٢، ثلاث، اثنين.
- مطابقة كلمات مثل: رز، أرز، زيت، سكر، صحون، تمر، شاي، حليب، مياه، أحذية، قميص.
- اختيار المنتجات المناسبة من متجر التاجر.
- اقتراح كميات.
- اقتراح سعر باقة.
- حساب السعر قبل العرض.
- حساب نسبة الخصم.
- حساب أقصى عدد باقات ممكنة حسب المخزون.

### 2) API لمساعد العروض
تم إنشاء:

```txt
app/api/merchant/offers/ai-suggest/route.ts
```

مثال payload:

```json
{
  "prompt": "اعمل لي عرض رمضان من 3 دبات زيت و2 كيس رز و3 صحون تقديم"
}
```

يرجع:
- عنوان مقترح.
- وصف مقترح.
- الأصناف المناسبة.
- الكميات.
- سعر الباقة المقترح.
- أقصى كمية باقات حسب المخزون.
- تحذيرات إذا لم يجد صنفاً مطابقاً.

### 3) دمج المساعد داخل شاشة إنشاء العرض
تم تعديل:

```txt
components/merchant/store-offer-form.tsx
```

وأضيف قسم:

```txt
مساعد العروض الذكي
```

التاجر يكتب فكرة العرض، ثم يضغط:

```txt
اقتراح عرض
```

فيقوم النظام بتعبئة:
- عنوان العرض.
- وصف العرض.
- نوع العرض = مجمع.
- الأصناف.
- الكميات.
- سعر الباقة المقترح.

ثم يطلب من التاجر الضغط على:

```txt
تجميع العرض
```

لمراجعة التفاصيل قبل الإرسال.

## أمثلة مدعومة

```txt
اعمل لي عرض رمضان من 3 دبات زيت و2 كيس رز و3 صحون تقديم
باقة تموين من رز وسكر وزيت
عرض من شاي وسكر وتمر
عرض من قميص وبنطلون وجاكيت
```

## الفحوصات
تم تنفيذ:

```bash
npm run typecheck
npm run lint
npm test
```

النتيجة:

```txt
TypeScript: PASS
ESLint: PASS
Tests: 12 passed
```

تمت محاولة:

```bash
npm run build
```

والـ compile نجح، لكن بيئة العمل الحالية توقفت بسبب حد ذاكرة Node أثناء مرحلة التحقق النهائية، كما حدث سابقاً:

```txt
JavaScript heap out of memory
```

هذا مرتبط بحدود بيئة العمل الحالية وليس بخطأ TypeScript أو lint.

## المرحلة التالية المقترحة
المرحلة التالية من الذكاء الاصطناعي:

1. مساعد توليد وصف المنتج.
2. اقتراح المتغيرات تلقائياً عند إضافة منتج.
3. مساعد الأدمن لتلخيص طلبات فتح المتاجر.
4. مساعد مراجعة إعلانات المتاجر.
