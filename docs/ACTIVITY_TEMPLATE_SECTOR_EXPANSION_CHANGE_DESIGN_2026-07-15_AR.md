# تصميم تغيير: توسعة قطاعات قوالب نشاط التاجر

**التاريخ:** 2026-07-15

## الهدف
توسيع taxonomy الجاهز بقطاعات أكثر دقة بعد وجود القوالب العامة للأثاث والأدوات المنزلية، من دون تحويلها إلى منتجات أو مخزون أو نظام قطاعي كامل.

## القطاعات الإضافية
- أجهزة منزلية وكهربائية.
- ديكور وسجاد وستائر.
- أقمشة وخياطة.
- جوالات وملحقات.
- كمبيوتر وألعاب.
- ذهب ومجوهرات وإكسسوارات.
- زراعة وري وبذور.
- جملة وتوزيع.

## الحوكمة
- كل قالب يحتوي أقساماً ووحدات وخصائص وقيم متغيرات حقيقية.
- لا أسعار أو مخزون أو منتجات أو شروط مالية.
- API upsert لا يحذف taxonomy قائم.
- تضاف keywords للتوصية تلقائياً اعتماداً على نشاط المتجر.

## الصيانة
- catalog ثابت ومختبر، مع إمكانية نقل مصدره لاحقاً إلى DB/versioned catalog إذا احتاج الأدمن تخصيصه دون نشر.
