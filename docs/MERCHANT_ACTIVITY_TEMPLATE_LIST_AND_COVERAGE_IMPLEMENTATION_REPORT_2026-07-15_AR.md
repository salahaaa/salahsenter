# تقرير تنفيذ: قوالب نشاط التاجر — قائمة مستطيلة ومعاينة وتغطية قطاعية

**التاريخ:** 2026-07-15
**الحالة:** مكتمل محلياً ومتحقق آلياً.

## واجهة الاختيار
تم استبدال مربعات القوالب القابلة للتطبيق المباشر بواجهة قائمة مستطيلة:
- بحث باسم النشاط أو التصنيفات.
- صف واحد لكل قالب مع ملخص صغير.
- اختيار قالب واحد واضح.
- معاينة تفصيلية قبل التطبيق: الأقسام والوحدات والخصائص والمقاسات والألوان.
- checkbox إقرار قبل التطبيق، بدلاً من browser confirm.
- لا ينشئ القالب منتجات أو مخزوناً أو أسعاراً أو قيوداً مالية.

## تغطية القوالب
القوالب كانت كافية كأساس taxonomy لقطاعات رئيسية، وتمت توسعتها بـ:
```text
مواد بناء / أدوات ومعدات
قطع غيار وزينة سيارات
كتب / قرطاسية ومكتبية
أطفال / ألعاب ومستلزمات
```

وتبقى القوالب القائمة للمطاعم والأزياء والأحذية والأثاث والجمال والسوبرماركت والتموين والخضار والمخابز واللحوم والألبان والمشروبات والإلكترونيات والصيدلية والخدمات.

## تحذيرات قطاعية
- قالب الصيدلية لا يفعّل وصفات طبية أو تتبع صلاحية/دفعات تلقائياً.
- قالب الخدمات لا يفعّل تقويماً أو نظام حجز تلقائياً.
- هذه التحذيرات تظهر قبل التطبيق حتى لا يوهم القالب التاجر بأنه نظام قطاعي كامل.

## API والبيانات
- GET يعرض تفاصيل المعاينة (الوحدات والخصائص والقيم) وليس counts فقط.
- POST بقي idempotent/upsert ولا يحذف taxonomy قائم.
- سجل التدقيق يبقى لكل تطبيق قالب.
- لا migration أو queue جديدة.
