# تقرير إضافة المقاسات والألوان للمنتجات — 2026-07-03

## الهدف
إضافة مقاسات متنوعة وألوان متعددة لمنتجات المحلات المستوردة من ملفات الواجهات، بحيث تصبح المنتجات أقرب إلى تشغيل Marketplace حقيقي بمتغيرات متعددة بدل منتج واحد فقط.

---

## ما تم تنفيذه

تم إنشاء سكربت احترافي:

```txt
scripts/enrich-store-product-options.ts
```

وإضافة أمر:

```bash
npm run enrich:product-options
```

يقوم السكربت بـ:

- إنشاء مقاسات `sizes` لكل متجر.
- إنشاء ألوان `colors` لكل متجر.
- إنشاء خصائص منتج:
  - `المقاس`
  - `اللون`
- إنشاء قيم الخصائص داخل `product_attribute_values`.
- تحويل المنتجات إلى `variable` عند الحاجة.
- إنشاء متغيرات منتجات متعددة `product_variants` حسب المقاس واللون.
- ربط كل متغير بقيم اللون والمقاس عبر `product_variant_attribute_values`.
- توزيع المخزون على المتغيرات بدون مخزون سالب.
- تسجيل حركات مخزون initial/add/adjust عند إنشاء المتغيرات الجديدة.

## ملاحظات
- لا توجد أي صور base64 مضافة.
- لم يتم تنفيذ migration schema؛ الإضافة تمت باستخدام الجداول الحالية.
- السكربت idempotent قدر الإمكان، ويمكن تشغيله لاحقاً لتحديث المتغيرات دون نسخ عشوائية.
- المتغيرات الجديدة مرتبطة بخصائص اللون والمقاس، وستفيد واجهة المنتج ولوحة التاجر والبحث مستقبلاً.

## توصيات لاحقة
1. تحسين واجهة صفحة المنتج لعرض اختيار اللون والمقاس بشكل أوضح إن لم تكن تعرض كل المتغيرات حالياً.
2. إضافة صور خاصة لكل لون لاحقاً للملابس والأحذية.
3. إضافة فلترة عامة حسب اللون والمقاس في صفحات المتجر والجناح.
4. إضافة bulk editor للتاجر لتعديل أسعار ومخزون المتغيرات بسرعة.
