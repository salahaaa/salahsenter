# تقرير اعتماد المقاسات والألوان كاقتراحات ذكية للتجار — 2026-07-03

## الهدف
اعتماد بيانات المقاسات والألوان والمتغيرات التي أضفناها للمتاجر، وتحويلها إلى قوالب ذكية تُقترح على التاجر حسب نشاطه، حتى لا يبدأ من الصفر عند تجهيز الأقسام والوحدات والمتغيرات.

---

## ما تم تنفيذه

### 1) توسيع قوالب النشاط
تم تحديث:

```txt
components/merchant/product-taxonomy-form.tsx
```

وأصبحت القوالب تشمل الآن:

- مطعم / كافيه.
- ملابس / أزياء.
- أحذية / رياضي ورسمي.
- أدوات منزلية / مطبخ ونظافة.
- أثاث ومفروشات.
- جمال / عطور وعناية.
- بقالة / سوبرماركت.
- إلكترونيات / جوالات.
- صيدلية / عناية صحية.
- خدمات / حجوزات.

---

### 2) إضافة المقاسات والألوان داخل القوالب
القوالب لم تعد تضيف الأقسام والوحدات والخصائص فقط، بل تضيف أيضاً:

- المقاسات داخل جدول `sizes`.
- الألوان داخل جدول `colors`.
- خصائص المنتج داخل `product_attributes`.
- قيم الخصائص داخل `product_attribute_values`.

مثال:

#### تاجر الملابس
يقترح له:

```txt
أقسام: رجالي، نسائي، أطفال، أحذية، إكسسوارات
مقاسات: XS, S, M, L, XL, XXL
ألوان: أسود، أبيض، أزرق، رمادي، بني، وردي
متغيرات: المقاس، اللون، الخامة
```

#### تاجر الأحذية
يقترح له:

```txt
أقسام: أحذية رجالية، أحذية نسائية، أحذية أطفال، أحذية رياضية، أحذية رسمية
مقاسات: 36 - 45
ألوان: أسود، أبيض، بني، رمادي، أزرق
متغيرات: المقاس، اللون، الاستخدام
```

#### تاجر الأدوات المنزلية
يقترح له:

```txt
أقسام: أدوات النظافة، أدوات المطبخ، التخزين والتنظيم، إكسسوارات الحمام، الإضاءة
مقاسات: صغير، متوسط، كبير، عائلي
ألوان: أبيض، أسود، رمادي، بيج، فضي
متغيرات: الحجم، اللون، الخامة
```

#### تاجر الأثاث
يقترح له:

```txt
أقسام: غرف معيشة، غرف نوم، طاولات، كراسي، ديكور، مفروشات
مقاسات: صغير، متوسط، كبير، عائلي
ألوان: رمادي، بيج، بني، أسود، طبيعي
متغيرات: المقاس، اللون، الخامة
```

#### تاجر الجمال والعطور
يقترح له:

```txt
أقسام: عطور، عناية بالبشرة، مكياج، عناية بالشعر، هدايا وتشكيلات
مقاسات/أحجام: 30ml, 50ml, 100ml, طقم
ألوان: ذهبي، وردي، أبيض، أسود
متغيرات: الحجم، الفئة، الرائحة
```

---

### 3) اقتراح القالب حسب نشاط المتجر تلقائياً
تمت إضافة منطق يقرأ:

- اسم المتجر.
- وصف المتجر.
- الأقسام الحالية.

ثم يقترح القوالب المناسبة في أعلى شاشة:

```txt
إعدادات الأصناف والمتغيرات
```

مثال:

- إذا كان المتجر يحتوي على كلمات مثل: ملابس، أزياء، رجالي، نسائي → يظهر قالب الملابس كموصى به.
- إذا كان النشاط: أحذية، حذاء، شوز، رياضي → يظهر قالب الأحذية.
- إذا كان النشاط: أدوات منزلية، مطبخ، نظافة، الصبري → يظهر قالب الأدوات المنزلية.
- إذا كان النشاط: أثاث، مفروشات، طاولات، كنب → يظهر قالب الأثاث.

---

### 4) جعل حفظ القوالب أكثر أماناً وعدم تكرار العناصر
تم تحسين APIs:

```txt
app/api/merchant/store-settings/route.ts
app/api/merchant/product-taxonomy/route.ts
```

التحسينات:

- عند إضافة مقاس موجود مسبقاً يتم تحديثه بدلاً من الفشل.
- عند إضافة لون موجود مسبقاً يتم تحديثه بدلاً من الفشل.
- عند إضافة خاصية بنفس الكود يتم تحديثها بدلاً من تكرارها.
- عند إضافة قيمة خاصية موجودة يتم تحديثها بدلاً من تكرارها.
- عند إضافة قسم بنفس الاسم يتم إرجاع القسم الموجود بدلاً من تكراره.

هذا يجعل زر "تطبيق القالب" آمناً إذا ضغطه التاجر أكثر من مرة.

## النتيجة العملية للتاجر
الآن عند دخول التاجر إلى:

```txt
لوحة التاجر → الأصناف والخصائص
```

سيجد:

1. قوالب عامة لكل الأنشطة.
2. قسم "اقتراحات ذكية مناسبة لنشاط متجرك" إذا تعرف النظام على نوع النشاط.
3. بضغطة واحدة يتم إنشاء:
   - الأقسام.
   - الوحدات.
   - المقاسات.
   - الألوان.
   - المتغيرات.
   - قيم المتغيرات.

وهذا يختصر وقت تجهيز المتجر بشكل كبير.

## توصيات لاحقة
1. ربط هذه القوالب أيضاً بشاشة فتح المتجر، بحيث يتم اقتراحها فور اعتماد التاجر.
2. إضافة زر داخل محرر المنتج: "توليد متغيرات من قالب النشاط".
3. جعل التاجر يختار أكثر من قالب إذا كان متجره متعدد النشاط، مثل: أزياء + أحذية + عطور.
4. إضافة معاينة مرئية للألوان والمقاسات قبل التطبيق.
