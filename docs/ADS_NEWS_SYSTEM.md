# نظام الإعلانات والأخبار متعدد المستويات

## ما تم تنفيذه

### 1) فصل إعلانات المول عن إعلانات المتاجر

- إعلانات المول: `announcements.level = marketplace` وتظهر في الصفحة الرئيسية فقط.
- إعلانات المتاجر: `announcements.level = store` وتظهر داخل صفحة المتجر فقط.
- أخبار المول: `news.level = marketplace` وتظهر في شريط أخبار المول.
- أخبار المتجر: `news.level = store` وتظهر في شريط أخبار المتجر داخل صفحة المتجر.

## 2) الصفحة الرئيسية للمول

تعرض فقط:

- شريط أخبار المول.
- بانرات المول.
- إعلانات المول العامة.
- عروض مميزة ممولة مستقبلاً من المنتجات المروجة فقط.
- المنتجات الرائجة.
- المتاجر الرائجة.
- الأجنحة.

لا يتم عرض إعلانات المتاجر أو أخبار المتاجر في الصفحة الرئيسية.

## 3) صفحة المتجر

تم تحسين قسم `العروض والأخبار` داخل صفحة المتجر ليظهر أسفل معلومات المتجر مباشرة، ويحتوي على:

- شريط أخبار متحرك خاص بالمتجر.
- بطاقات عروض وإعلانات المتجر.
- صورة اختيارية.
- عنوان.
- وصف مختصر.
- تاريخ النشر.
- تاريخ الانتهاء وعدد الأيام المتبقية.
- زر عرض التفاصيل.
- شارة مثبت أو مروج.

## 4) إعدادات وحدود الإعلانات

تمت إضافة إعدادات إعلانات مركزية في:

```txt
/admin/ads
```

وتتحكم في:

- الحد الأقصى لإعلانات المتجر المجانية النشطة.
- الحد الأقصى لأخبار المتجر النشطة.
- عدد إعلانات المول المعروضة في الرئيسية.
- عدد بطاقات عروض المتجر.
- عدد أخبار شريط المتجر.
- تفعيل/تعطيل قسم العروض المميزة الممولة.

API:

```txt
/api/admin/advertising-settings
```

## 5) دعم الإعلانات المدفوعة مستقبلاً

الحقول موجودة مسبقاً داخل `announcements` و `products`:

```txt
is_promoted
promotion_start
promotion_end
promotion_package
```

وقسم `عروض مميزة` في الصفحة الرئيسية يعرض المنتجات المروجة فقط ضمن نافذة الترويج.

## 6) حماية UX

- لا يتم إغراق الصفحة الرئيسية بعروض المتاجر الفردية.
- كل متجر يمتلك مساحته التسويقية داخل صفحته فقط.
- إعلانات المول تبقى مهمة ومركزة.
- النظام جاهز للإعلانات المدفوعة دون إعادة هيكلة.
