# تقرير تنظيف المشروع والوسائط المحلية

**التاريخ:** 14 يوليو 2026  
**النطاق:** تنظيف آمن للملفات الكبيرة القابلة لإعادة الإنشاء، والتحقق من مجلد/صور `image-search` بناءً على طلب المستخدم.

## القرار المنفذ

تم اعتماد **تنظيف آمن فقط**؛ أي لم يتم حذف أي source code أو migrations أو lockfile أو snapshots الخاصة بـDrizzle أو `.git`.

## فحص `image-search` والصور المستوردة

- لم يوجد أي مجلد باسم أو مطابق لـ`image-search` داخل المشروع.
- لم توجد ملفات صور محلية/مستوردة بصيغ `png/jpg/jpeg/gif/webp/avif` خارج `.git` أو `node_modules`.
- لا توجد أصول صور tracked داخل Git يمكن حذفها من المصدر.

لذلك **لم يُحذف أي ملف صورة**؛ لأن حذفه لم يكن ممكناً أو مطلوباً عملياً داخل filesystem الحالي.

> توجد مراجع صور عن بُعد أو وسائط قد تُحفظ لاحقاً في قاعدة البيانات/التخزين الخارجي. لم تُمس، لأنها ليست ملفات داخل المشروع، وحذفها يحتاج قراراً منفصلاً وسياسة بيانات حتى لا تُكسر صور المنتجات والبنرات الموجودة في قاعدة البيانات.

## الملفات والمجلدات المحذوفة

| المسار | السبب | هل يمكن استعادته؟ |
|---|---|---|
| `node_modules/` | اعتمادات npm كبيرة مولدة محلياً | نعم، عبر `npm ci` |
| `coverage/` | ناتج تغطية اختبارات مولد | نعم، عبر `npm run test:coverage` |
| `tsconfig.tsbuildinfo` | كاش TypeScript | نعم، يولد عند typecheck/build |
| `.config/` | إعداد محلي مولد إن وجد | نعم، يولد من الأداة التي تستخدمه |

## أثر التوسع والصيانة

- لا يوجد أثر وظيفي أو schema/API من هذا التنظيف.
- إبقاء `package-lock.json` يضمن استعادة dependencies نفسها بصورة قابلة للتكرار.
- لا يتم تضمين `node_modules` أو coverage في تسليم المصدر أو Git.
- على أي بيئة تطوير أو CI جديدة، ينفذ:

```bash
npm ci
```

ثم يمكن تشغيل الفحوصات المعتادة.

## التوافق والتراجع

- لا يلزم migration أو rollback للبيانات.
- إذا احتاج المشروع إلى أدوات التطوير مجدداً، `npm ci` هو التراجع الآمن.
- لا توجد صور محلية حذفت لاستعادتها.

## التحقق

- تأكدت إزالة جميع مسارات التنظيف الأربعة.
- تأكد عدم وجود `image-search` أو ملفات صور محلية مستوردة في المشروع.
- لم يُشغّل lint/typecheck/tests بعد التنظيف عمداً، لأن الاعتمادات حُذفت. آخر فحص كامل قبل التنظيف كان ناجحاً؛ وعند الحاجة يعاد `npm ci` ثم الفحص.
