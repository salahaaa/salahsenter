# Sponsored Products Ads Platform

## Routes
```txt
/merchant/ads
/admin/ads-platform
/api/merchant/ad-campaigns
/api/admin/ad-campaigns
```

## Ad Types
- Sponsored Products
- Featured Products
- Homepage Banner
- Category Banner

## Tables
```txt
ad_campaigns
ad_clicks
ad_impressions
ad_billing
ad_reports
```

## Merchant Metrics
- CTR
- CPC
- ROAS
- Clicks
- Impressions
- Conversions
- Budget and spend

## Admin Controls
- Approve/reject campaigns
- Activate/pause/end campaigns
- Audit logs on status changes

## Ranking Algorithm Foundation
Sponsored placement should combine:
```txt
ad bid + campaign quality + product rating + product sales + store quality
```
A service-level ranking hook can be connected to search/homepage placements.
